# AWS PartyRock Daily Task Scheduler

An AI-powered daily planning assistant built with **AWS PartyRock** to help students and professionals organize tasks, manage deadlines, and create realistic daily schedules.

> **Project Status:** In Progress

## Overview

The AWS PartyRock Daily Task Scheduler is a productivity application designed to help users plan their day based on task priorities, deadlines, estimated durations, and personal scheduling preferences.

The application will use AI to generate a chronological daily schedule, identify potential scheduling conflicts, and provide recommendations for improving productivity.

This project is part of my hands-on learning journey with AWS AI tools and cloud-based application development.

## Objectives

- Build an AI-powered daily scheduling application using AWS PartyRock.
- Generate realistic schedules based on user availability and task requirements.
- Analyze task priorities and deadlines.
- Identify overloaded schedules and scheduling conflicts.
- Provide practical productivity recommendations.
- Document the development process, testing results, and project limitations.

## Planned Features

### 1. Task Management
Users will be able to provide task names, descriptions, priorities, deadlines, and estimated completion times.

### 2. AI Schedule Generation
Generate a chronological daily schedule based on the user's available hours, task requirements, and scheduling preferences.

### 3. Priority Analysis
Explain the reasoning behind task ordering and highlight important deadlines and priorities.

### 4. Schedule Feasibility
Identify when tasks exceed the available time and recommend adjustments to the workload.

### 5. Productivity Recommendations
Suggest focus sessions, breaks, buffer time, and practical ways to manage the day's workload.

### 6. End-of-Day Checklist
Provide a checklist of planned tasks to help users track their daily responsibilities.

## Technology Stack

- **AWS PartyRock:** AI-powered application generation and prototyping.
- **Generative AI:** Natural-language task analysis, scheduling, and productivity recommendations.
- **GitHub:** Version control, project documentation, and portfolio presentation.

## How It Works

The planned workflow is:

1. Enter tasks, deadlines, priorities, and estimated durations.
2. Specify available hours, break preferences, and fixed commitments.
3. Select a scheduling preference.
4. Generate a daily schedule and task priority analysis.
5. Review feasibility warnings and productivity recommendations.
6. Use the end-of-day checklist to review planned responsibilities.

## Testing Plan

The application will be tested using the following scenarios:

- A manageable workload that fits within the available time.
- An overloaded day with more tasks than can reasonably be completed.
- Tasks with different priorities and deadlines.
- Fixed commitments that restrict scheduling availability.
- Different break durations and scheduling preferences.
- Missing or incomplete task information.

Testing will focus on schedule consistency, chronological ordering, feasibility warnings, and the relevance of AI-generated recommendations.

Detailed test results will be documented in `docs/testing-results.md`.

## Limitations

As an AI-powered prototype, the application may produce inaccurate or inconsistent schedules. Generated schedules should be reviewed by the user, particularly when deadlines and fixed commitments are involved.

The initial project will focus on AI-assisted planning rather than a fully automated calendar integration or persistent task management system. Actual capabilities will depend on AWS PartyRock's supported features.
